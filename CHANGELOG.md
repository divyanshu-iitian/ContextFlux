# Changelog

All notable changes to ContextFlux are documented here.

## [0.1.0] - 2026-07-30

### Added

- Incremental local repository index with source provenance.
- Task routing for exploration, test discovery, review context, traces, and edit ripple.
- Reciprocal-rank fusion across lexical, path/symbol, graph, and workflow rankings.
- Exact measured context-packet budgets and token reduction reporting.
- Read-only MCP server, CLI, TypeScript library API, and coding-agent skill.
- Reproducible benchmark runner with a plain lexical baseline.
